# RAG Knowledge Assistant

An AI-powered knowledge assistant built with Python.

## Objectives

- Learn LLM application engineering.
- Implement document ingestion.
- Generate text embeddings.
- Implement vector retrieval.
- Build context-grounded question answering.

## Technology Stack

- Python 3.12
- uv
- NumPy
- Pandas
- Pydantic
- pytest
- Ruff

## Installation

Clone the repository:

    git clone https://github.com/tejadamgt-commits/rag-knowledge-assistant

Navigate into the project:

    cd rag-knowledge-assistant

Install dependencies:

    uv sync

Run tests:

    uv run pytest -v

Run linting:

    uv run ruff check .
